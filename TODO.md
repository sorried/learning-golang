# План изучения Go

## Основы

- [ ] Установить Go и разобраться с `go version`, `go run` и `go build`
- [ ] Создать первый модуль с помощью `go mod init`
- [ ] Изучить переменные, типы, константы и преобразование типов
- [ ] Освоить условия, циклы, `switch` и `defer`
- [ ] Попрактиковаться со строками, массивами, срезами и map
- [ ] Написать функции и изучить несколько возвращаемых значений

## Структуры и ошибки

- [ ] Освоить структуры, методы и указатели
- [ ] Разобраться с интерфейсами и композицией
- [ ] Научиться обрабатывать ошибки и создавать собственные ошибки
- [ ] Изучить пакеты и организацию проекта

## Практика

- [ ] Написать простую программу для командной строки
- [ ] Покрыть функции тестами с помощью `testing`
- [ ] Освоить горутины, каналы и `context`
- [ ] Написать небольшой HTTP-сервис на `net/http`
- [ ] Добавлять сюда новые заметки и задачи по мере обучения
